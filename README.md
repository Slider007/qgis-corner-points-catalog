# Угловые точки и ведомость координат

Модуль QGIS: выделенные угловые точки → таблица координат (№ угла, широта и
долгота в градусах-минутах-секундах, X и Y в МСК субъекта).

## Как пользоваться

1. Сделайте слой угловых точек активным и выделите нужные точки.
2. Нажмите кнопку на панели «Альтан-Эко» (или «Модули → Альтан-Эко → Ведомость
   координат выделенных угловых точек»).
3. Через несколько секунд откроется таблица «Ведомость координат — <слой>».

Столбцы: «№ угла», «Широта (WGS-84)», «Долгота (WGS-84)» в виде `55°16′40,21″`,
«X, м (МСК-50 зона 1)» (на север), «Y, м (МСК-50 зона 1)» (на восток), «Субъект»,
«МСК». Если точки из разных субъектов, МСК у каждой строки своя, а в заголовке X/Y
её нет — она в столбце «МСК». Строки идут по возрастанию номера. Слой точек не меняется.

№ угла берётся из поля слоя, название которого содержит «№», «угол», «номер» или
равно `num`. Если такого поля нет, модуль спросит, из какого поля брать номер, или
пронумерует точки по порядку.

**В Excel:** правой кнопкой по таблице → «Экспорт → Сохранить объекты как…», формат
XLSX, флажок «Use aliases for exported name» — тогда заголовки будут русскими.

## Как определяется МСК

Как в модуле «СК проекта: UTM и МСК»: субъект РФ — по месту каждой точки через
сервис адресов OpenStreetMap (нужен интернет; сервис разрешает запрос в секунду,
поэтому около секунды на точку, ход виден внизу окна QGIS, расчёт можно отменить),
зона — с ближайшим осевым меридианом.

В OpenStreetMap уходят только координаты выделенных точек — широта и долгота.
Названия слоя и проекта, поля и прочие данные не передаются. Если выделено больше
100 точек, модуль сначала скажет, сколько времени это займёт, и напомнит, что МСК
можно задать вручную — тогда интернет не нужен. Точка на самой границе субъектов получает МСК
того субъекта, который вернул сервис.

Встроено 253 МСК по 80 субъектам (тот же набор, что в «СК проекта»). Параметры
взяты из рабочего набора и официально не проверялись.

## В панели инструментов анализа

Тот же расчёт — «Угловые точки → Ведомости координат → Ведомость координат угловых
точек». Там можно выбрать ГСК-2011 вместо WGS-84, задать МСК вручную для всех точек
(интернет не нужен), поле номера и число знаков после запятой (по умолчанию 2).

Требуется QGIS 3.40 или новее, рассчитан и на QGIS 4 (в QGIS 4 не проверялся).
